# 评测用例（evals/cases）

这里的每个 `.json` 文件是一条评测用例，供 `CreativeWorkshopEval` 跑 `direct` / `agent` / `deep`
（以及后续接入的 `agentic`）几条管线做对比。**用例内容必须由作者本人提供**——不得由 AI 编造
作者的想法、素材或初稿，否则评测结果没有意义。

## 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 用例唯一标识，建议用 `case-01` 这种可排序的短名，决定报告里的展示顺序。 |
| `kind` | 是 | 只能是 `"idea"` 或 `"draft"`。`idea` = 只有一个想法，从零开始成稿；`draft` = 已有初稿，评测管线在此基础上修订。 |
| `idea` | 是 | 一句话说清楚这篇文章要写什么。至少 10 个字符，太短无法构成有意义的生成/修订目标。 |
| `direction` | 是 | 文章方向/体裁，例如"情感文学随笔""经典文本再解读"，用于匹配作者的 Style Profile。 |
| `materials` | 否 | 支撑写作的素材片段（真实经历、观察、引用等）。留空也可以，但有素材的用例更接近真实使用场景。 |
| `content` | `kind=draft` 时必填 | 已有初稿正文。`kind=draft` 时至少 80 个字符，太短不足以体现真实修订场景；`kind=idea` 时留空字符串 `""`。 |

任何一个字段不满足上述要求，评测程序会在启动时直接报错退出（报错信息会点名文件名、字段、期望），
不会静默跳过非法用例。

## 用例数量与配比建议

- 总量建议 **10–20 个**，覆盖不同方向/体裁，避免评测结果被单一题材主导。
- `kind=idea` 和 `kind=draft` 建议**各占一半**：前者考察"从零成稿"，后者考察"诊断+修订"，
  两种能力的评测信号不能互相替代。
- **推荐"一鱼两吃"配对法**（当前用例库即按此组织，如 case-01/case-04）：同一个题材建两个用例，
  `idea` 和 `direction` 和 `materials` 三个字段完全一致，一个 `kind="idea"`（content 留空）、
  一个 `kind="draft"`（content 放你的真实成稿）。同题对照能把"从零成稿"和"诊断+修订"的
  差距测得最干净，还自动满足配比要求。

## JSON 格式提醒（容易踩的坑）

- **JSON 没有多行字符串**，不支持 Python 式的 `"""..."""` 三引号写法。长正文必须写成
  一整个字符串：换行是 `\n`，正文里的英文双引号是 `\"`。
- 别手工转义长正文。把文章存成 `.md` 文件后用一条命令生成转义好的字符串：

  ```bash
  jq -Rs '.' 你的文章.md
  ```

  把输出整体粘到 `"content":` 后面即可；或者直接把 md 文件交给 AI 助手转换。

## 敏感内容提醒

素材和初稿往往来自真实生活片段，添加用例前请自行脱敏：

- 去掉真实姓名、可定位到具体人的关系描述（如"我表姐""XX 公司同事"可以泛化为"一位亲戚""同事"）；
- 去掉具体地址、电话、账号等可识别信息；
- 如果某段经历本人不愿意进入版本库（哪怕脱敏后），就不要作为用例——评测不值得用隐私换来。

## 示例：一组"一鱼两吃"配对

同一题材、同样的 `idea` / `direction` / `materials`，只有 `kind` 和 `content` 不同。
示例 id 用 `case-98` / `case-99` 只是为了不和真实文件重号——**实际添加时请顺着你现有编号
往下排**（先 `ls` 看一眼目录，避免覆盖已有用例）。

`kind=idea`（从零成稿，content 留空）：

```json
{
  "id": "case-98",
  "kind": "idea",
  "idea": "写一篇关于\"深夜整理旧照片\"的随笔，聊聊数字时代的记忆为什么反而更容易被遗忘。",
  "direction": "情感文学随笔",
  "materials": "上周清理手机相册，翻到三年前的照片，很多场景已经完全想不起来当时的细节了。",
  "content": ""
}
```

`kind=draft`（同题材的真实成稿，考察诊断+修订）：

```json
{
  "id": "case-99",
  "kind": "draft",
  "idea": "写一篇关于\"深夜整理旧照片\"的随笔，聊聊数字时代的记忆为什么反而更容易被遗忘。",
  "direction": "情感文学随笔",
  "materials": "上周清理手机相册，翻到三年前的照片，很多场景已经完全想不起来当时的细节了。",
  "content": "在这里粘贴至少 80 个字符的真实初稿正文（用上面的 jq 命令从 md 文件转义），评测管线会基于它跑写作诊断和修订。"
}
```
